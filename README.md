# Trailmark

تتبّع مسار أوفلاين بالكامل لأندرويد — مشي، جري، دراجة، ومشي جبلي.

- **محلي**: بلا حساب، بلا سحابة. اتصال شبكي فقط عند طلب المستخدم تحميل منطقة خرائط/توجيه.
- **Kotlin / Jetpack Compose / MapLibre / GraphHopper / SQLDelight**.
- **تسجيل**: خدمة أمامية، إيقاف مؤقت، استئناف بعد قتل العملية، ودجت وإشعار حيّان.
- **وسائط وتصدير**: كاميرا داخل التطبيق، Photo Picker، ومعرض نسخ احتياطي؛ فيديو تحليق MP4 (30 إطاراً، 3D/2D/نظرة عامة، 15/30/60 ث) بالصور والفيديوهات ونقاط الاهتمام.
- **بياناتك**: نسخ احتياطي/استعادة ZIP، تصدير GPX/FIT/TCX، ومزامنة Health Connect.
- الترخيص: MIT.
