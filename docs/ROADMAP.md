# Trailmark — الحالة وخارطة الطريق

آخر تحديث: 2026-10-17 (جولة ليلية).

المرجع الملزم: `docs/superpowers/specs/2026-10-16-trailmark-design.md`.

## ما أُنجز فعلياً

| المجال | الحالة |
|---|---|
| المعمار | Kotlin/Compose أصلي، متعدّد الوحدات (11 وحدة)، كل شيء يُبنى ويُختبَر على CI |
| المحرّك | منقول بالكامل: بوابة الضجيج، رفض الاندفاع، R39/R40، النبضة، الخمول، التقسيمات + 21 اختباراً |
| البيانات | SQLDelight (activity/track_point/track_state/flags) + استئناف بعد القتل |
| التسجيل | خدمة أمامية (نوع location) + wake lock + كتابة فورية + بوابة ر7 + جودة + خمول |
| GPS | `LocationManager` حقيقي (زمن أحادي من `elapsedRealtimeNanos`)، الدقة غير المقاسة = sentinel |
| الخرائط | MapLibre 11.7 + PMTiles أوفلاين (`pmtiles://file://`)، خريطة حيّة على شاشة التسجيل، خريطة في التفاصيل |
| تحكم الخريطة | تكبير/تصغير وبوصلة + زر العودة إليّ + تتبّع تلقائي بالاتجاه (heading-up) أثناء التسجيل |
| المؤشرات على الخريطة | أيقونة سيليت احترافية لكل رياضة (دراجة مع درّاج، عدّاء، ماشٍ، متسلق) على قرص داكن بإطار، الشبح بنفس الشكل شفافاً في موقعه الحيّ |
| ملاحة | نقطة موقع دائمة + دائرة دقة خارج الجلسات، زر العودة إليّ يعمل فوراً حتى بلا تسجيل، بناءات ثلاثية الأبعاد (`fill-extrusion` من `render_height`) |
| المظهر | خريطة داكنة / فاتحة (الأنماط: OpenFreeMap dark / positron والأوفلاين بلوحة ألوان مقابلة) + زر تبديل محفوظ |
| المحفّز الحيّ | عبارات شبح متغيرة حسب من المتقدّم (بالأمتار) + رصد التجاوز/التجاوز المضاد برسالة خاصة لثوانٍ |
| مناطق الخرائط | مستودع `trailmark-maps` + CI يبني PMTiles من OSM (Planetiler) وينشرها مع manifest + SHA-256 |
| التحليل | `analyze`, `Ghost`, `Segment` (JVM) + عرض الصعود/أقصى سرعة |
| المحفّز النصّي | `:coach` ثلاثي اللغة + سطر قبل الجلسة + الشبح الحيّ |
| الاستيراد/التصدير | GPX كاتب/قارئ + TCX + مشاركة GPX + استيراد GPX عبر منتقي الملفات |
| الرياضات | مشي/جري/دراجة/مشي جبلي (محرّك + شاشة) |
| اللغات | عربي/فرنسي/إنجليزي + RTL/LTR كامل + وحدات مخصّصة |
| الإتاحة | هامش أشرطة النظام (targetSdk 35)، أهداف لمس ≥44dp، contentDescription |

## أدوات التحقق (لأنني لا أرى الصور)

- `tools/ui_audit.ps1` — يحلّل شجرة واجهة الجهاز (uiautomator) ويرصد: تجاوز الحدود، تراكب العناصر، أهداف اللمس الصغيرة. نتائج الجولة: نظيفة عدا عنصر نسبة MapLibre (21×21dp، مكوّن خارجي).
- محاكاة حركة على الجهاز: `SyntheticFixSource` + `am start --ez synthetic true` — تُثبت المسار والخريطة والأرقام والشبح بلا عتاد GPS.

## تسميات الخريطة (أُنجزت)

- توليد SDF glyphs في CI (`glyphs.yml`) عبر `fontnik` من Noto Sans (لاتيني) + Noto Naskh Arabic (عربي)، ranges 0–2303.
- تُنسخ إلى `filesDir` عند أول تشغيل، والستايل يشير إلى `file://<dir>/{fontstack}/{range}.pbf`.
- طبقات نصية: أسماء المدن (`place`)، أسماء الطرق (`transportation_name`)، أسماء المياه (`water_name`)، مع تفضيل `name:ar` ثم `name:fr` ثم `name`.
- ملاحظة: التطبيق القديم كان فيه `text-font` لكن **بلا glyphs** — لذلك لم تظهر أي تسميات فيه.

## مشكلة محلولة

- حزم فرنسا/المغرب كانت تخرج ~80KB: السبب أن `bounds` في سير العمل يتجه افتراضياً إلى مربع الجزائر العاصمة. أُصلح (default فارغ + بوابة جودة 1MB + تسجيل bounds في المانيفست). النتيجة النهائية: الجزائر 19.6MB، تونس 15.1MB، المغرب 47.8MB، فرنسا 501.9MB (نجحت في 19m51s).

## خريطة الطريق المتبقية

1. **مراجعة ما بعد التسجيل على طريقة Strava** (الأولوية التالية): صفحة تفاصيل غنية لساعات طويلة باستئناس: تكبير المسار (تبسيط Douglas–Peucker للعرض)، مخططات سرعة/ارتفاع، تقسيمات كيلومترية، إعادة تشغيل متحركة للمسار مع شريط زمني وسرعات ×1/×4/×16/×60 كما في Flyover.
2. **تصدير فيديو رحلة (3D Flyover)** — تحليق كاميرالي متتابع على المسار → MP4 عبر MediaCodec/EGL. عمل أكبر؛ يُنفَّذ بعد إعادة التشغيل داخل التطبيق.
3. **حزم بلدان إضافية حسب الحاجة** — اختيارية الآن: الأونلاين يغطي العالم والحزم للأوفلاين فقط. إضافة أي بلد = dispatch بـ`area` (مسار Geofabrik).
4. **دعم حزم متعددة في وقت واحد**: اختيار الحزمة حسب bbox الموقع الحالي (الآن يستعمل أول حزمة مثبّتة).
5. **FIT** استيراد/تصدير (نقل تاريخ Garmin/Strava بالكامل) + استيراد دفعة ZIP.
6. **التوجيه والملاحة الأوفلاين** (GraphHopper) — لم يبدأ.
7. **المقاطع في الواجهة** (إنشاء/عرض) — المنطق جاهز في `:analytics`، ينقص ربط UI + تخزين.
8. **Health Connect / Wear OS**.
9. **البحث عن أماكن على الخريطة** (geocoding) — زر البحث كما في قوقل ماب.
10. **التوجيه الصوتي** (مرشد صوتي للمنعطفات) — يرتبط بالبند 6.
11. **صفحة الإعدادات**: اللغات والثيمات والوحدات — أُجّل بقرار المستخدم (الواجهة الحالية مقبولة)؛ مظهر الخريطة صار زرّاً مباشراً الآن.
12. **تقييم الانتقال إلى MapLibre Compose** (غلاف Compose الرسمي الأحدث) — تحسين مستقبلي، ليس عاجلاً.

## كيف يضيف أي شخص بلده؟

1. Actions في `trailmark-maps` → `build-pack` → Run workflow، مع `area` = مسار Geofabrik (مثل `europe/italy`) و`bounds` فارغ أو مربّع مدينة و`max_zoom`.
2. الحزمة تُنشر تلقائياً وتُضاف إلى `manifest.json` (تراكمي).
3. في التطبيق: «الخرائط» → تنزيل.

## ملاحظات صحة (صريحة)

- التسميات تعمل الآن: glyphs مدمجة (عربي/لاتيني) + تفضيل `name:ar`.
- الخريطة الافتراضية أونلاين (OpenFreeMap) بالعالم كله؛ الحزم الأوفلاين بديل عند انقطاع الشبكة، ومناطق MapLibre تغطي أي مكان عند الطلب.
- حزمة المدينة (z14) تعطي تفاصيل شوارع داخل حدودها فقط؛ حزمة البلد (z12) نظرة عامة.
- لم تُجرَّب بعد على مسار ميداني حقيقي (خارج المكتب).
