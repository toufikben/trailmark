# Trailmark — الحالة وخارطة الطريق

آخر تحديث: 2026-10-20 (بناء مستمر — بعد إضافة تطبيق Wear OS وتصدير فيديو MP4).

المرجع الملزم: `docs/superpowers/specs/2026-10-16-trailmark-design.md`.

## ما أُنجز فعلياً

| المجال | الحالة |
|---|---|
| المعمار | Kotlin/Compose أصلي، متعدّد الوحدات (12 وحدة تشمل `:wear`)، كل شيء يُبنى ويُختبَر على CI |
| المحرّك | منقول بالكامل: بوابة الضجيج، رفض الاندفاع، R39/R40، النبضة، الخمول، التقسيمات + 21 اختباراً |
| البيانات | SQLDelight (activity/track_point/track_state/flags) + استئناف بعد القتل |
| التسجيل | خدمة أمامية (نوع location) + wake lock + كتابة فورية + بوابة ر7 + جودة + خمول — يعمل والشاشة مطفأة |
| الإيقاف المؤقت | زر إيقاف مؤقت/استئناف: تجميد الزمن والمسافة، تجاهل النقاط أثناء الوقوف، فصل المقاطع بلا قفزات مسافة، وحفظ نقطة استعادة أثناء الوقوف |
| GPS | `LocationManager` حقيقي (زمن أحادي من `elapsedRealtimeNanos`)، الدقة غير المقاسة = sentinel |
| الخرائط | MapLibre 11.7 + PMTiles أوفلاين (`pmtiles://file://`)، خريطة حيّة على شاشة التسجيل، خريطة في التفاصيل |
| تحكم الخريطة | تكبير/تصغير وبوصلة + زر العودة إليّ + تتبّع تلقائي بالاتجاه (heading-up) أثناء التسجيل |
| المؤشرات على الخريطة | شخصيات متحركة مرسومة إجرائياً لكل رياضة: درّاج بعجلات دوّارة وبدالات حقيقية عبر IK، عدّاء بخطوات وذراعين متقابلتين، ماشٍ، متسلق بحمّالة وعصا — 8 إطارات looping بسرعة تناسب السرعة اللحظية؛ الشبح بنفس الهيئة شفافاً |
| ملاحة | نقطة موقع دائمة + دائرة دقة خارج الجلسات، زر العودة إليّ يعمل فوراً حتى بلا تسجيل، بناءات ثلاثية الأبعاد (`fill-extrusion` من `render_height`) |
| تخطيط المسار | صفحة سفر جديدة: اختيار الوجهة بالضغط على الخريطة، مسار يتبع الطرق مع ارتفاع من BRouter (احتياطي: خط مباشر بوسم واضح)، وقت وصول مقدّر لكل رياضة (سرعة ثابتة + عقوبة صعود)، إحصاء الصعود/النزول/أقصى انحدار، تلوين التدرّج (أحمر حاد ← أخضر نزول) + مقطع ارتفاع ملوّن — مع **وضع مسودة**: شريط مصغّر (نقاط + تراجع + مسح + تمّ) أثناء جمع النقاط، ولوحة الإحصاءات الكاملة تظهر فقط بعد «تمّ»؛ **وحفظ المسارات**: زر حفظ يخزّن المسار المخطط محلياً (JSON، حتى 50 مساراً) وقائمة «مسارات محفوظة» من زر في الأعلى لإعادة الفتح أو الحذف |
| التوجيه الصوتي | إرشاد منعطفات من المسار المخطط، مشتق هندسياً بلا خدمة خارجية: يسار/يمين/حاد/التفاف مع مسافة تُقاس بالسرعة، وبطاقة على شاشة التسجيل تعرض المنعطف القادم أو المسافة المتبقية، وتنبيه «خارج المسار» بعد 20 ثانية خارجه — عربي/فرنسي/إنجليزي |
| المظهر | خريطة داكنة / فاتحة (الأنماط: OpenFreeMap dark / positron والأوفلاين بلوحة ألوان مقابلة) + زر تبديل محفوظ + **هوية التطبيق**: أيقونة تكيّفية (تدرّج ليلي + شمس + جبلان + مسار متقطّع) وشاشة بداية متحركة (عدّاء/درّاج/متسلّق يتحركون نحو الجبل مع رسم المسار) |
| المحفّز الحيّ | عبارات شبح متغيرة حسب من المتقدّم (بالأمتار) + رصد التجاوز/التجاوز المضاد برسالة خاصة لثوانٍ |
| مناطق الخرائط | مستودع `trailmark-maps` + CI يبني PMTiles من OSM (Planetiler) وينشرها مع manifest + SHA-256 |
| التحليل | `analyze`, `Ghost`, `Segment` (JVM) + عرض الصعود/أقصى سرعة |
| المقاطع | إنشاء من أي نشاط (شريطا تمرير للبداية/النهاية + تسمية)، مطابقة آلية على الإيقاف وفتح التفاصيل، تعبئة تاريخية لكل الأنشطة عند الإنشاء، بطاقة مقاطع في التفاصيل (زمنك/الأفضل/رقم قياسي) — كله على الجهاز |
| الرسوم البيانية | مخططا سرعة/ارتفاع في التفاصيل (sparkline مملوء مع أقصى قيمة، عيّنات ≤120 نقطة) |
| المحفّز النصّي | `:coach` ثلاثي اللغة + سطر قبل الجلسة + الشبح الحيّ |
| الاستيراد/التصدير | GPX كاتب/قارئ + TCX + مشاركة GPX + استيراد GPX عبر منتقي الملفات |
| الرياضات | مشي/جري/دراجة/مشي جبلي (محرّك + شاشة) |
| اللغات | 16 لغة (عربي/فرنسي/إنجليزي/إسباني/برتغالي/ألماني/إيطالي/هولندي/بولندي/روسي/تركي/إندونيسي/هندي/ياباني/كوري/صيني) + RTL/LTR كامل + حفظ اختيار اللغة + تواريخ محلية |
| الإتاحة | هامش أشرطة النظام (targetSdk 35)، أهداف لمس ≥44dp، contentDescription |
| الإنجازات | 17 إنجازاً محلياً حسب المسافة/السرعة/الصعود + بطاقة في «تقدّمي» |
| الأرقام القياسية | أسرع 1/5/10 كم عبر كل الأنشطة (نافذة منزلقة على المسافة) + بطاقة في «تقدّمي» |
| الوسائط | التقاط صور/فيديو أثناء التسجيل مع شده إلى المسار، معرض في التفاصيل، عارض داخلي |
| فيديو التحليق | تصدير MP4 داخل التطبيق: كاميرا تتابع المسار بزاوية 55° مع مقدمة تكبير، 720×1280 بمعدل 24 إطاراً، ترميز H.264 عبر MediaCodec + MediaMuxer، ومشاركة الملف من شاشة التفاصيل |
| ساعة Wear OS | تطبيق مستقل في وحدة `:wear`: تسجيل GPS بخدمة أمامية، مسافة وزمن حيّان، كتابة GPX، وإرسالها إلى الهاتف عبر قناة Wearable حيث تُستورد تلقائياً إلى سجل النشاطات |
| بطاقة المشاركة | بطاقة ستوري 1080×1920 (المسار + الأرقام، نصوص مُشكّلة عبر StaticLayout) تُشارَك كصورة |
| الطقس | طقس حيّ على شاشة التسجيل (يجلب من الخدمة لا الواجهة) + طقس الوجهة + أفضل نافذة زمنية في «تخطيط مسار» |
| المالية | تجربة 15 يوماً كاملة الميزات ثم قفل عناصر Pro؛ شراء شهري/سنوي/مدى الحياة عبر Play Billing؛ استرجاع + مزامنة استحقاق تسحب Pro عند انتهاء الاشتراك؛ استحقاق لا يُمنح إلا بعد تأكيد العملية |
| مناطق أوفلاين | رسم منطقة وتنزيلها من الخريطة مع حدود البلاطات، مناطق محفوظة قابلة للحذف، وحزم بلدان جاهزة ببوابة Pro |
| التوجيه دون اتصال | سير عمل `build-routing` في `trailmark-maps` يبني رسم GraphHopper للطرق (profile: foot + bike) من OSM وينشره مع `routing-manifest.json` (نفس مخطط الحزم)؛ التطبيق: قسم «توجيه دون اتصال» في شاشة المناطق لتنزيل الرسم والتحقق من SHA-256 وفكّه إلى `filesDir/routing/<region>-gh`، ثم تخطيط المسار يعمل من الرسم المحلي عند تعذّر BRouter (BRouter ← GraphHopper ← خط مباشر) |
| الوحدات | مترية/إمبراطورية من الإعدادات: مسافات (كم/ميل)، وتيرة (دقائق/كم أو /ميل)، سرعة (كم/س أو ميل/س)، ارتفاع (م/قدم) — محفوظة وتُطبَّق على كل الشاشات وبطاقة الستوري |
| جودة | تدقيق مستقل على أربعة محاور (واجهة/منطق/أمن-دفع/كود) أُصلحت منه كل ملاحظات P0/P1 + اختبارات وحدات (تنسيق، تجربة، مؤشر النقاط، أرقام قياسية) |

## أدوات التحقق (لأنني لا أرى الصور)

- `tools/ui_audit.ps1` — يحلّل شجرة واجهة الجهاز (uiautomator) ويرصد: تجاوز الحدود، تراكب العناصر، أهداف اللمس الصغيرة. نتائج الجولة: نظيفة عدا عنصر نسبة MapLibre (21×21dp، مكوّن خارجي).
- محاكاة حركة على الجهاز: `SyntheticFixSource` + `am start --ez synthetic true` — تُثبت المسار والخريطة والأرقام والشبح بلا عتاد GPS.

## تسميات الخريطة (أُنجزت)

- توليد SDF glyphs في CI (`glyphs.yml`) عبر `fontnik` من Noto Sans (لاتيني) + Noto Naskh Arabic (عربي)، ranges 0–2303.
- تُنسخ إلى `filesDir` عند أول تشغيل، والستايل يشير إلى `file://<dir>/{fontstack}/{range}.pbf`.
- طبقات نصية: أسماء المدن (`place`)، أسماء الطرق (`transportation_name`)، أسماء المياه (`water_name`)، **وتتبع لغة التطبيق**: `name:<language>` ثم `name` (يُعاد بناء الستايل فور تغيير اللغة).
- ملاحظة: التطبيق القديم كان فيه `text-font` لكن **بلا glyphs** — لذلك لم تظهر أي تسميات فيه.

## مشكلة محلولة

- حزم فرنسا/المغرب كانت تخرج ~80KB: السبب أن `bounds` في سير العمل يتجه افتراضياً إلى مربع الجزائر العاصمة. أُصلح (default فارغ + بوابة جودة 1MB + تسجيل bounds في المانيفست). النتيجة النهائية: الجزائر 19.6MB، تونس 15.1MB، المغرب 47.8MB، فرنسا 501.9MB (نجحت في 19m51s).

## خريطة الطريق المتبقية

1. ~~**مراجعة ما بعد التسجيل على طريقة Strava**~~ — أُنجزت: إعادة التشغيل المتحركة (سرعات ×1/×4/×16/×60، توقف تلقائي عند وسائط، شريط تمرير) + بطاقة ستوري + أرقام قياسية 1/5/10 كم + مخططا سرعة/ارتفاع + تبسيط Douglas–Peucker للعرض (4م على الخريطة، 6م في بطاقة الستوري).
2. ~~**تصدير فيديو رحلة (3D Flyover)**~~ — أُنجز: زر «تحليق» في التفاصيل يشغّل الإعادة من البداية بسرعة ×16، ميل 55°، كاميرا تتابع المسار؛ وزر «تصدير فيديو» يرمّز MP4 (H.264 عبر MediaCodec، 720×1280، 24 إطاراً) ويشاركه من التطبيق.
3. **حزم بلدان إضافية حسب الحاجة** — اختيارية الآن: الأونلاين يغطي العالم والحزم للأوفلاين فقط. إضافة أي بلد = dispatch بـ`area` (مسار Geofabrik). أُطلق حديثاً: إسبانيا/إيطاليا/البرتغال (خلف بعضها في طابور CI).
4. ~~**دعم حزم متعددة في وقت واحد**~~ — أُنجز: قراءة حدود bbox من ترويسة PMTiles v3 مباشرة، واختيار الحزمة التي تحتوي الموقع المعروض في الخريطة/التخطيط/التسجيل، مع الرجوع لأول حزمة عند عدم التطابق.
5. ~~**FIT**~~ — أُنجز الاستيراد والتصدير (كاتب/قارئ ثنائي مع CRC، ترويسات مضغوطة، endian مفرد) + مشاركة .fit من التفاصيل + استيراد تلقائي حسب البصمة في السجل + **استيراد دفعة ZIP** (GPX وFIT، أي عدد من الملفات في أرشيف واحد).
6. ~~**التوجيه والملاحة الأوفلاين** (GraphHopper)~~ — أُنجز: سير عمل `build-routing` يبني رسم foot/bike وينشره، والتطبيق ينزّل الرسم من شاشة المناطق ويفكّه ويستخدمه عند تعذّر BRouter.
7. ~~**المقاطع في الواجهة** (إنشاء/عرض)~~ — أُنجزت: إنشاء من التفاصيل، مطابقة آلية، تعبئة تاريخية، بطاقة أزمنة في التفاصيل، بطاقة كل المقاطع في «تقدّمي»، ومشاركة نصية للمقطع (الاسم + أفضل زمن + الإحداثيات) بالنقر.
8. ~~**Health Connect**~~ — أُنجز: مزامنة كل نشاط منتهٍ (جلسة تمرين + مسافة + سعرات حراريّة مقدَّرة بالوزن) مع أذونات الكتابة وزرّ ربط/تنزيل في الإعدادات. تطبيق الساعة أُنجز لتسجيل ونقل GPX، لكن مزامنة Health Connect من الساعة نفسها ما زالت متبقية.
9. ~~**البحث عن أماكن على الخريطة** (geocoding)~~ — أُنجز: حقل بحث في «تخطيط مسار» عبر Nominatim (تأخير 450مث، نتائج مع الإسناد، النقر يعيّن الوجهة).
10. ~~**التوجيه الصوتي**~~ — أُنجز للمسارات المخططة: اشتقاق المنعطفات من هندسة المسار (نافذة 30م، عتبة 35°، دمج 45م)، إعلان قبل 45–120م حسب السرعة، وتنبيه «خارج المسار» بعد 20 ثانية مع تهدئة دقيقتين. التوجيه الأوفلاين الكامل (بند 6) ما زال مفتوحاً.
11. ~~**صفحة الإعدادات**: أُنجزت (لغات 16 + مظهر الخريطة + وحدات مترية/إمبراطورية).~~
12. ~~**تقييم الانتقال إلى MapLibre Compose**~~ — أُنجز التقييم: نبقى على MapLibre Android SDK 11.7. أحدث غلاف (0.20.0) يطلب Kotlin 2.4.20 وCompose 1.12.1 وCoroutines 1.11.0 وطبقة `nativeffi` جديدة، ولا يضمن تكافؤ PMTiles المحلي وتعديل الستايل وقت التشغيل ولقطات الفيديو. التفاصيل وشروط إعادة التقييم في `docs/maplibre-compose-eval.md`.
13. ~~**فصل خط المسار عند نقاط الخمول**~~ — أُنجز: `splitRuns` في core/geo يقسم المسار عند IDLE؛ الخريطة (4م) وبطاقة الستوري (6م) ترسمان الآن عدة خطوط بدل القفزات الوهمية.
14. **التحقق على الجهاز المتبقي**: تبسيط Douglas–Peucker، مخططات السرعة/الارتفاع، وإعادة تشغيل شاشة التفاصيل على نشاط حقيقي متحرك. جديد: الإشعار الحي (مسافة+زمن كل 5ث)، بطاقة المقاطع في «تقدّمي»، بحث الأماكن، تصدير/استيراد FIT مع Garmin/Strava، استيراد دفعة ZIP، اختيار الحزمة حسب الموقع، ومزامنة Health Connect (ربط الأذونات + ظهور النشاط في التطبيقات الصحية). أُنجز على الجهاز: شريحة الملاحة أثناء التسجيل (المتبقي/المنعطف/خارج المسار)، وضع المسودة في التخطيط، تحلّق 3D، تمرير شاشة التفاصيل، وإصلاح تجاوز صف أزرار التصدير (FlowRow) وسباق كاميرا الخريطة عند الفتح (كانت تبقى على تكبير العالم). يبقى التحقق من: تنزيل رسم التوجيه وفكّه، تصدير فيديو MP4 (الصوت/الترميز على أجهزة مختلفة)، وتطبيق Wear OS على ساعة حقيقية (التسجيل، إرسال القناة، الاستيراد على الهاتف).

## كيف يضيف أي شخص بلده؟

1. Actions في `trailmark-maps` → `build-pack` → Run workflow، مع `area` = مسار Geofabrik (مثل `europe/italy`) و`bounds` فارغ أو مربّع مدينة و`max_zoom`.
2. الحزمة تُنشر تلقائياً وتُضاف إلى `manifest.json` (تراكمي).
3. في التطبيق: «الخرائط» → تنزيل.

## ملاحظات صحة (صريحة)

- التسميات تعمل الآن: glyphs مدمجة (عربي/لاتيني) + تفضيل `name:ar`.
- الخريطة الافتراضية أونلاين (OpenFreeMap) بالعالم كله؛ الحزم الأوفلاين بديل عند انقطاع الشبكة، ومناطق MapLibre تغطي أي مكان عند الطلب.
- حزمة المدينة (z14) تعطي تفاصيل شوارع داخل حدودها فقط؛ حزمة البلد (z12) نظرة عامة.
- لم تُجرَّب بعد على مسار ميداني حقيقي (خارج المكتب).
- إعداد منتجات Play Console (`pro_monthly` / `pro_yearly` / `pro_lifetime`) وأسعارها لم يُنجز بعد — الكود جاهز.
- نسخة احتياطية من مفتاح التوقيع (`trailmark-upload.jks` + كلمات المرور) إلزامية قبل أي نشر — فقدانه يمنع تحديث التطبيق مستقبلاً.
- أدوات هذه الجولة (بطاقة ستوري، نافذة الطقس، فصل طبقات الخريطة، التحميل التدريجي للمسار، المقاطع، مخططات السرعة/الارتفاع، التبديل بين الوحدات، ترحيل قاعدة البيانات v3→v4) تحتاج تحققاً على جهاز حقيقي قبل الإصدار.
