# Trailmark — مواصفة التصميم المعماري

- التاريخ: 2026-10-16
- الحالة: مسودة للمراجعة قبل كتابة خطة التنفيذ
- المعمار: Kotlin / Jetpack Compose أصلي بالكامل (Android فقط)
- المستودع: `trailmark` — الترخيص: MIT

> Trailmark = علامة تُوضع على الدرب لتأكيد الطريق.

---

## 1. الهدف

أفضل تطبيق تتبّع مسار أوفلاين، يتفوّق على Strava وGarmin Connect في الدقة، البطارية، الخرائط الأوفلاين، التحليل، والتحفيز. كل شيء محلي: بلا حساب، بلا سحابة، وبلا شبكة إلا عند طلب المستخدم تحميل منطقة.

الجمهور: مشي، جري، دراجة، مشي جبلي — عربياً وفرنسياً وإنجليزياً.

المحرّك القديم (`track_scribe` Dart) مُقاس على أدلة جهاز؛ ننقل قواعده ونعيد كتابة البنية.

## 2. معايير النجاح

1. تسجيل متواصل 6 ساعات بدقة عالية ضمن ميزانية بطارية مُقاسة مقابل منافس.
2. مسار صحيح بشاشة مطفأة وفي الجيب، مؤكَّد بجولة جهاز.
3. خرائط متّجهية مع تضاريس وتظليل، بلا شبكة بعد التحميل.
4. استيراد/تصدير GPX وFIT وTCX بلا فقدان.
5. محفّز نصّي يعتمد تاريخ المستخدم بثلاث لغات، بلا صوت افتراضياً.
6. صفر اتصال شبكي غير صريح، وصفر نسخ سحابي لقاعدة البيانات.

## 3. خارج النطاق

- iOS / سطح مكتب / ويب.
- حساب مستخدم أو مزامنة سحابية أو لوحات صدارة.
- بثّ صوتي (TTS اختياري وافتراضياً مُطفأ).

## 4. المعمار — وحدات Gradle

```
:app                    التطبيق، التنقّل، الصلاحيات، DI
:core:model             نماذج النطاق (Fix, StoredPoint, Activity, Segment)
:core:geo               هافرسين/اتجاه/مقياس            [منقول]
:core:time              زمن أحادي (elapsedRealtimeNanos)[منقول]
:core:ui                التوكنات والثيم ومكوّنات Compose
:engine                 قواعد التسجيل النقية           [منقول + اختباراته]
:sensors                GPS، BLE، ANT+، بارومتر
:recording              Foreground Service + الربط
:data                   Room (WAL) + مخزن ملفّات
:maps                   MapLibre + PMTiles + تضاريس
:routing                GraphHopper أوفلاين + مناطق + ملاحة
:analytics              مقاطع، سجلّات، أحمال، اتجاهات، VO2max
:coach                  المحفّز النصّي
:portable               استيراد/تصدير GPX/FIT/TCX
:feature:recording|summary|history|detail|plan|segments|settings
```

الاعتماد اتجاه واحد: `feature → محرّكات → (data|engine) → core`.
قاعدة صلبة: `:engine` و`:core:*` بلا Android، تُختبَر على JVM.
DI: Hilt. Async: Coroutines + Flow. UI: Compose + Material 3.

## 5. المكوّنات

**5.1 المحرّك `:engine`** — نقل بوابة التخزين التي تتبع الضجيج، رفض الاندفاع، استعادة المِرساة (R40)، علامة النبضة (R101)، آلة الخمول (R6)، الانضباط الأحادي، `displayablePoints`، `computeSplits`. يُنقل معه ~40 اختباراً (بما فيها اختبارات الإفساد الذاتي) كأمان انحدار.

**5.2 الاستشعار `:sensors`** — واجهة `FixSource` موحّدة. GPS (`LocationManager`/Fused، دقة عالية، `distanceFilter=0`)، BLE (نبط/خطوات/قدرة)، ANT+ عند توفر العتاد (تُتحقّق رخصة SDK)، بارومتر للارتفاع. كل مصدر قابل للاستبدال بمصدر وهمي.

**5.3 التسجيل `:recording`** — خدمة أمامية نوع location؛ كل نقطة تُكتب فوراً بسلسلة كتابة واحدة؛ نقطة استئناف (آخر نقطة + مسافة + زمن تراكمي)؛ استئناف بعد القتل؛ فشل تخزين لا يوقف التسجيل.

**5.4 البيانات `:data`** — Room/SQLite بوضع WAL. جداول: `activities`, `track_points`, `track_state` (استئناف), `app_flags`, `segments`, `segment_efforts`, `sensor_devices`, `regions`. الدقة غير المقاسة تُخزَّن NULL (sentinel). مخزن ملفّات للخرائط/DEM/رسم التوجيه. أداة ترحيل مرة واحدة من قاعدة `track_scribe.sqlite`.

**5.5 الخرائط `:maps`** — MapLibre Native + PMTiles متّجهية بطبقات مكدّسة (bbox/zoom)، تضاريس + DEM + تظليل، طبقات: مسار متدرّج بالسرعة، ارتفاع، بداية/نهاية، العلامة المتحركة. عالمي بتحميل مناطق عند الطلب.

**5.6 التوجيه `:routing`** — GraphHopper أوفلاين (Apache-2)، تخطيط حسب الرياضة، ملاحة منعطف بمنعطف، إدارة مناطق (تحميل/حذف/تحديث).

**5.7 التحليل `:analytics`** — مقاطع، أجزاء الكيلومتر، إيقاع، تدرّج، زمن حركة/توقف، سجلّات شخصية، أحمال واتجاهات، تقدير VO2max.

**5.8 المحفّز `:coach`** (§7).

**5.9 الاستيراد/التصدير `:portable`** — GPX/FIT/TCX استيراداً وتصديراً، مشاركة صورة للمسار.

**5.10 العلامة المتحركة حسب الرياضة** — SymbolLayer في MapLibre أو طبقة Compose؛ sprite-sheet لكل رياضة بإطارات حركة؛ الدوران حسب `bearingDeg`؛ الإيقاع حسب `speedMps`؛ الخمول ⇒ وضعية وقوف؛ نفس الرمز في إعادة تشغيل التفاصيل.

## 6. الواجهة والهوية

هوية جديدة من الصفر: لغة تصميم رياضية داكنة، Material 3، نظام ألوان جديد، تدرّجات سرعة/درجة، رسوم نظيفة، قانون تباين WCAG. دعم RTL/LTR كامل.

الشاشات: التسجيل (خريطة ملء الشاشة + علامة متحركة + شريط أرقام)، ملخّص ما بعد الجلسة (مقارنة تاريخية)، التفاصيل/التحليل، السجل (فلاتر واتجاهات)، التخطيط والملاحة، المقاطع، الإعدادات (مناطق، بيانات، أجهزة، لغة، خصوصية).

## 7. المحفّز النصّي `:coach`

محرّك قواعد محلي + بنك قوالب (ar/fr/en) + مقارنة بتاريخ المستخدم:
- قبل الجلسة: «آخر مرة 10 كم في 52:10 — تكسرها اليوم؟ لا تكون كسول 😉»
- أثناء: حسب المرحلة/السرعة/مقابل الشبح.
- بعد: إنجاز + مقارنة + هدف مقترح.
- تنويع المُبدِّل ببذرة عشوائية؛ بلا صوت افتراضياً.

## 8. المكتبات (متساهلة فقط)

MapLibre Native (BSD) · GraphHopper (Apache-2) · PMTiles (BSD) · Room · Hilt · Coroutines · maplibre-navigation · BLE عبر Android API · ANT+ SDK (تُتحقّق رخصته). FIT/TCX من مكتبة مفتوحة موثّقة الرخصة.

## 9. الأخطاء والصلاحيات

صفر شبكة إلا عند تحميل منطقة. `ACCESS_FINE_LOCATION` + خدمة أمامية + `allowBackup=false`. فشل تخزين ⇒ استمرار + بانر. القيم المخزّنة المجهولة تُعالَج بلا انهيار.

## 10. الاختبار

`:engine`/`:core` JUnit سريع (نقل اختبارات Dart). `:data` Room in-memory + ملفّ حقيقي للدوام. `:recording` Robolectric + مستشعرات وهمية. UI اختبارات Compose. ميداني: fixtures جهاز حقيقية.
